# Использование ИИ

Агент изучил существующий Go-код, миграции, Compose, тесты и отчёты, затем добавил
RabbitMQ, outbox и наблюдаемость. Пользователю не приписывается ручное тестирование.

Сохранены транзакции PostgreSQL для владения и результата. Новые решения: атомарный
outbox через триггер, publisher confirms с mandatory, ручной ACK, prefetch=1,
DLQ и периодическая сверка незавершённых заданий. Добавлены метрики и трассировка.
При проверке кода исправлена ошибка publisher: результат пустого чтения outbox
не должен сохраняться на следующую итерацию. Проверки и фактические результаты
V2 находятся отдельно в `results/v2/`, включая неудачные запуски.

Нужно независимо проверить протокол ACK/confirm, ограничения reconciliation,
конфигурацию доступа и реальные требования к нагрузке. Наличие quorum queue на
одном узле не означает HA. Автоматические проверки не заменяют аудит, испытания
восстановления из резервных копий или длительную нагрузку на целевом окружении.
